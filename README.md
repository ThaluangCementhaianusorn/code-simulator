# ห้องเรียนพัฒนาเว็บแอปพลิเคชัน (Code Simulator) v2.1

สื่อการสอนแบบปฏิสัมพันธ์ รายวิชา **31909-2009 การพัฒนาเว็บแอปพลิเคชัน** (ท-ป-น 2-3-3 · 3 หน่วยกิต)
เขียน HTML / CSS / JavaScript / Vue 3 / Bootstrap 5 แล้วเห็นผลบน **หน้าจอมือถือจำลอง** ทันที ใช้ Google Apps Script + Google Sheet เป็นฐานข้อมูล

> คำอธิบายรายวิชา: ศึกษาและปฏิบัติเกี่ยวกับหลักการออกแบบเว็บแอปพลิเคชันโดยใช้เฟรมเวิร์ก หลักการพัฒนาเว็บแอปพลิเคชันโดยใช้เฟรมเวิร์กที่ได้รับความนิยมในปัจจุบัน การเชื่อมต่อฐานข้อมูล การตกแต่งเว็บแอปพลิเคชันด้วยสไตล์ชีตเฟรมเวิร์ก และอัปโหลดเว็บไซต์ขึ้นบนระบบเครือข่ายอินเทอร์เน็ต

## ใหม่ในรุ่น 2.1
- **หน้าตาใหม่ + แดชบอร์ดกราฟทุกหน้า**: หน้าแรกเต็มจอ (ข้อมูลรายวิชา สถิติ และช่องเข้าสู่ระบบ) · นักศึกษา: ความก้าวหน้ารายภารกิจ สถานะกิจกรรม การส่งงานรายวัน คะแนนตามประเภท ระดับเกียรติบัตร · ครู: แนวโน้มการส่งงาน สถานะผู้เรียน ผู้ผ่านรายภารกิจ การกระจายคะแนน เฉลี่ยรายห้อง/รายภารกิจ โครงสร้างรายวิชา (กราฟทุกอันชี้/แตะเพื่อดูค่า และกด "ดูเป็นตาราง" ได้ รองรับโหมดมืด ไม่ใช้ไลบรารีภายนอก)
- **ครูแก้ไข PIN นักศึกษาได้**: หน้าครู → นักศึกษา → 🔑 PIN หรือ แก้ไข → "แก้ไข PIN เข้าสู่ระบบ" (ตัวเลข 4–8 หลัก หรือ 🎲 สุ่ม) PIN เดิมใช้ไม่ได้ทันทีและปลดล็อกกรณีใส่ผิดหลายครั้ง
- **ลายเซ็นครูผู้สอนและผู้อำนวยการบนเกียรติบัตร**: หน้าครู → ตั้งค่า → ✍️ ลายเซ็นบนเกียรติบัตร อัปโหลดภาพ (ระบบทำพื้นหลังโปร่งใส ครอป และย่อขนาดให้) หรือเซ็นบนหน้าจอ เก็บในแท็บ Settings (`signer1Sig`, `signer2Sig`)
- **กันคัดลอก/ทุจริต**
  - ใบงานและแบบฝึกทุกข้อ: บล็อกการวาง/ลากข้อความจากภายนอกลงพื้นที่ทำงาน (คัดลอก-วางภายในงานของตัวเองหรือข้อความในระบบได้) แจ้งเตือนทันที บันทึกให้ครูเห็น และ**หักคะแนน** `integrityPenalty`% ของคะแนนเต็มต่อครั้ง (ค่าเริ่มต้น 10%)
  - แบบทดสอบ: ห้ามเลือก/คัดลอกข้อสอบ คลิกขวา พิมพ์ หรือวางคำตอบจากภายนอก ตรวจจับการสลับแท็บ/ออกจากหน้าสอบ → แจ้งเตือนทุจริตและหักคะแนน ครบ `quizMaxStrikes` ครั้ง (ค่าเริ่มต้น 2) **ส่งคำตอบและให้ออกจากการสอบทันที** พร้อมบันทึกว่าทุจริต
  - สุ่มลำดับข้อและตัวเลือกทุกครั้ง และสุ่มจากคลังข้อสอบได้ด้วย `drawCount` (เช่น คลัง 20 ข้อ สุ่มให้ทำ 10 ข้อ)
  - ครูเห็นประวัติในแดชบอร์ด (🚨 แจ้งเตือนทุจริตล่าสุด) สมุดคะแนน (คอลัมน์ 🚨) และรายละเอียดรายคน · ถ้าเป็นความผิดพลาด ใช้ "ล้างการส่งงานรายกิจกรรม" ลบประวัติของกิจกรรมนั้น · ตั้งค่าได้ที่ ตั้งค่า → กันการคัดลอกและทุจริต
- **ภารกิจฐานข้อมูล 5 ภารกิจ** (`Content3.gs`): ตัวจำลอง Google Apps Script ในเบราว์เซอร์ (`lang: "gas"`) มี `SpreadsheetApp` (หลายแท็บ), `LockService`, `MailApp`, `Utilities.formatDate`, `PropertiesService`, `Logger` แสดงชีตเป็นแท็บแบบ Google Sheets ช่องที่เปลี่ยนเป็นสีเหลือง และกล่องอีเมลที่ส่ง · ชุดตรวจอ้างเซลล์ข้ามแท็บ `cell("Loans!A3")` `cells("Report!A2:F4")` `values("Students")` `lastRow("Loans")` `sheetNames()` `mails()` `lockUsed()` · ทุกภารกิจมีข้อมูลชุดซ่อน (`tests[].sheets`)
- **ภารกิจคะแนนพิเศษ**: ตั้งภารกิจเป็น "⭐ คะแนนพิเศษ" ได้ (หน้าครู → เนื้อหา → แก้ไขภารกิจ → ประเภทคะแนน) ไม่นับรวมคะแนนหลัก ไม่ล็อกตามลำดับ ไม่เป็นเงื่อนไขจบหลักสูตร แต่ได้เกียรติบัตร "ภารกิจพิเศษ" · เปิด/ปิดได้ด้วยสถานะ แสดง/ซ่อน เหมือนภารกิจอื่น
- **อัปเกรดจาก 2.0**: วางไฟล์ใหม่ทั้งหมด (เพิ่ม `Content3`) แล้วเลือกเมนู "1) ติดตั้งระบบ" (แท็บ `Integrity` และคอลัมน์ `Units.kind` จะถูกสร้างให้อัตโนมัติแม้ไม่รันก็ตาม) จากนั้น "3) ใส่เนื้อหา…" หรือนำเข้าเฉพาะภารกิจใหม่ผ่านหน้าครู

## สิ่งที่ระบบทำได้
- **ภารกิจ = หน่วยการเรียนรู้** แต่ละภารกิจมี 📖 ใบความรู้ → 📝 ใบงาน → 💻 แบบฝึกปฏิบัติ → ✅ แบบทดสอบ (10 ภารกิจ / 40 กิจกรรม / ตัวอย่างโค้ดรันได้ 40+ จุด)
- **ตัวจำลองเว็บ + หน้าจอมือถือ**: ตัวแก้ไขโค้ดธีมมืด (ปิดแท็กอัตโนมัติ) · หน้าจอเปลี่ยนตามทันทีที่พิมพ์ (⚡ สด) · สลับ 📱 มือถือ 360px / 💻 จอคอม 1024px · Console แสดง `console.log`, error พร้อมคำอธิบายภาษาไทยและไฮไลต์บรรทัด, การเรียก API · หยุดลูปไม่รู้จบ · ดาวน์โหลดเป็น `index.html`
- **ฐานข้อมูลจำลอง** `fetch("/api/ตาราง")` รองรับ GET (ค้นหา `?q=`) POST PUT PATCH DELETE ตาราง students, products, rooms, bookings, repairs และ `localStorage` จำลอง ฝึก CRUD ได้โดยไม่ต้องมีเซิร์ฟเวอร์
- **📱 ระบบตัวอย่าง 10 ระบบ** โค้ดเต็มพร้อมใช้ เปิดดูได้แม้ยังไม่เข้าสู่ระบบ
- **ตรวจงานอัตโนมัติ** ด้วยรายการตรวจหน้าเว็บ (DOM, CSS, คลิก/พิมพ์จำลอง, ข้อมูลในฐานข้อมูล) รวมรายการที่ซ่อนไว้, คำใบ้ทีละขั้น (หักคะแนนตามที่ตั้ง), จำกัดจำนวนครั้ง, ใช้คะแนนดีที่สุด
- **แบบทดสอบ**: ปรนัย / ถูก-ผิด / ทายผลลัพธ์ของ `console.log` / เติมคำ, สุ่มข้อและตัวเลือก, จับเวลาด้วยนาฬิกาเซิร์ฟเวอร์, ส่งอัตโนมัติเมื่อหมดเวลา, เฉลยเมื่อใช้สิทธิ์ครบ
- **เก็บคะแนนรายบุคคล** + สมุดคะแนน (ส่งออก CSV) + ครูเปิดดูโค้ดที่ส่งทุกครั้ง + ปรับคะแนน (บังคับใส่เหตุผล บันทึก Log)
- **เกียรติบัตรทุกภารกิจ** ออกอัตโนมัติเมื่อทำครบและได้ ≥ 60% (🥇 ≥90% / 🥈 ≥75% / 🥉 ผ่าน) + เกียรติบัตรสำเร็จหลักสูตร, พิมพ์ A4 แนวนอน, มี QR และลิงก์ตรวจสอบความถูกต้อง
- **ภารกิจถัดไปปลดล็อก** เมื่อผ่านภารกิจก่อนหน้า (ปิดได้ใน Settings)
- **⚙️ ตั้งค่า / แก้ไข / ลบข้อมูล**: แก้ Settings ทั้งหมด (ตรวจค่าก่อนบันทึก), เปลี่ยนรหัสผ่านครู, ลบภารกิจ/กิจกรรม (เลือกลบคะแนนด้วยได้), ลบนักศึกษาแบบซ่อน (กู้คืนได้) หรือถาวร (พิมพ์รหัสยืนยัน), ล้างการส่งงาน, ลบการปรับคะแนน, เพิกถอนเกียรติบัตร ทุกการลบบันทึก Log
- **เชื่อม GitHub ↔ Google Sheet**: หน้าเว็บบน GitHub Pages อ่าน/เขียน Google Sheet โดยตรงทุกครั้ง และเมื่อ push เข้า main แล้ว GitHub Actions จะอัปเดตทั้งหน้าเว็บและ Apps Script ให้เอง
- หลังบ้านครู: ภาพรวม (รีเฟรชอัตโนมัติทุก 30 วินาที), สมุดคะแนน, นักศึกษา (นำเข้าจาก Excel + พิมพ์บัตร PIN), เกียรติบัตร, แก้ไขเนื้อหาโดยไม่แก้โค้ด + 🧪 ทดสอบเฉลยกับชุดทดสอบ + ส่งออก/นำเข้า JSON

## ติดตั้งบน Google Apps Script
1. พิมพ์ `sheets.new` สร้าง Google Sheet → ตั้งชื่อ เช่น "ห้องเรียนพัฒนาเว็บแอป v2.1"
2. ส่วนขยาย → Apps Script → สร้างไฟล์ตามโฟลเดอร์ `src/` ให้ครบ **ชื่อตรงกัน**
   - Script (.gs): `Code`, `Core`, `Content`, `Content2`, `Content3`, `Setup` (ไฟล์ Code.gs เดิมให้ลบของเดิมแล้ววาง)
   - HTML: `App`, `Styles`, `Lib`, `Runner`, `WebRunner`, `Showcase`, `Cert`, `Student`, `Teacher` (ไม่ต้องพิมพ์ .html)
3. กด Ctrl+S → เลือกฟังก์ชัน `setup` → ▶ Run → อนุญาตสิทธิ์
4. กลับไปที่ Sheet กดรีเฟรช → เมนู **⚙️ ตั้งค่าระบบ** → 2) ตั้งรหัสผ่านครู → 3) ใส่เนื้อหาและนักศึกษาตัวอย่าง
5. แก้แท็บ **Settings**: ชื่อสถานศึกษา, ชื่อผู้ลงนามเกียรติบัตร, logoUrl ฯลฯ
6. Deploy → New deployment → Web app → Execute as **Me** → Who has access **Anyone** → คัดลอกลิงก์ `/exec`
   - นักศึกษา: `/exec` · ครู: `/exec?page=admin`
7. เพิ่มนักศึกษาจริง: หน้าครู → นักศึกษา → นำเข้ารายชื่อ (วางจาก Excel) → พิมพ์บัตร PIN แจก แล้วใช้เมนู "ล้างนักศึกษาตัวอย่าง"
8. แก้โค้ดภายหลัง: Deploy → Manage deployments → ✏️ → New version (ลิงก์เดิมไม่เปลี่ยน)

ถ้าใช้ clasp: `clasp clone <SCRIPT_ID>` แล้วคัดลอกไฟล์ใน `src/` ลงโฟลเดอร์นั้น → `clasp push`

## เผยแพร่ผ่าน GitHub (เชื่อม Google Sheet แบบเรียลไทม์)
ระบบมี 2 ส่วน คือ **หน้าเว็บ** บน GitHub Pages กับ **ฐานข้อมูล** Google Sheet ซึ่งเข้าถึงผ่าน Apps Script Web app
หน้าเว็บส่งทุกคำขอไปที่ `/exec` โดยตรงและไม่มีแคช จึงเห็นข้อมูลล่าสุดใน Sheet เสมอ

1. ติดตั้ง Apps Script ตามหัวข้อด้านบนให้เสร็จ แล้ว Deploy แบบ **Who has access: Anyone** (ไม่ต้องล็อกอิน Google)
   - ทดสอบ: เปิด `<ลิงก์ /exec>?api=ping` ในเบราว์เซอร์ ต้องเห็น `{"ok":true,...}`
2. แก้ไฟล์ `web/config.js` ใส่ลิงก์ `/exec`
   ```js
   window.CS_CONFIG = { apiUrl: 'https://script.google.com/macros/s/XXXX/exec' };
   ```
   (ถ้าเว้นว่าง จะเป็นโหมดสาธิตที่เก็บข้อมูลในเบราว์เซอร์)
3. สร้าง repo แล้ว push
   ```
   git init && git add . && git commit -m "Code Simulator"
   gh repo create code-simulator --public --source . --push
   ```
4. ใน GitHub ไปที่ **Settings → Pages → Source: GitHub Actions** แล้วรอ workflow "Deploy web to GitHub Pages" ทำงานเสร็จ
   - นักศึกษา: `https://<user>.github.io/code-simulator/` · ครู: `.../?page=admin`
   - ถ้าเชื่อมต่อสำเร็จ มุมขวาบนของหน้าครูจะแสดง 🟢 GitHub ↔ Google Sheet

### (ไม่บังคับ) ส่งโค้ด `src/` ขึ้น Apps Script อัตโนมัติ
workflow `apps-script.yml` จะรัน `clasp push` และอัปเดต Web app เดิมทุกครั้งที่มีการแก้ไฟล์ใน `src/`
1. เปิด Apps Script API ที่ https://script.google.com/home/usersettings
2. บนเครื่องตัวเอง รัน `npm i -g @google/clasp@2.4.2` → `clasp login` แล้วคัดลอกเนื้อหาไฟล์ `~/.clasprc.json`
3. ใน GitHub ไปที่ Settings → Secrets and variables → Actions → New repository secret

   | ชื่อ | ค่า |
   |---|---|
   | `CLASPRC_JSON` | เนื้อหาไฟล์ `~/.clasprc.json` |
   | `SCRIPT_ID` | Apps Script → Project Settings → Script ID |
   | `DEPLOYMENT_ID` | (ไม่บังคับ) Deploy → Manage deployments → Deployment ID ใส่เพื่อให้ลิงก์ `/exec` เดิมอัปเดตตาม |

> `.clasprc.json` คือสิทธิ์เข้าถึงบัญชี Google ของคุณ ห้าม commit ลง repo (ใส่ไว้ใน `.gitignore` แล้ว) ให้เก็บใน Secrets เท่านั้น

## เพิ่ม/แก้เนื้อหา
หน้าครู → เนื้อหา → แตะกิจกรรม → แก้ JSON → กด **🧪 ทดสอบเฉลย** ให้ผ่านก่อน → บันทึก
- ใบความรู้: `content` เป็น Markdown, บล็อก ```` ```html ```` และ ```` ```js ```` รันบนหน้าจอมือถือได้ทันที (```` ```html norun ```` = แสดงอย่างเดียว)
- ใบงาน/แบบฝึก: `tasks[]` → `title, prompt, lang (html|js), starterCode, hints[], solution, tests[{label, check, expected, score, hidden, compare}]`
  - `check` = โค้ด JavaScript (async) ที่รันในหน้าเว็บของผู้เรียน แล้ว `return` ค่ามาเทียบกับ `expected` เช่น `await click("#plus"); return text("#count")`
  - ตัวช่วย: `text(sel)` `texts(sel)` `val(sel)` `count(sel)` `exists(sel)` `css(sel, prop)` `attr(sel, name)` `click(sel)` `type(sel, ค่า)` `submit(sel)` `wait(ms)` `waitFor(fn|sel)` `logs` `db` `store(key)` `$` `$$`
  - ทุกชุดตรวจใช้หน้าเว็บใหม่ (ความกว้าง 360px) สถานะจึงไม่ปนกัน
  - `compare`: `trim` (ค่าเริ่มต้น) | `exact` | `ignorespace` | `contains` | `number` (ทศนิยมคลาดได้ 0.01)
- แบบทดสอบ: `questions[]` → `type`: `mc` (choices + answer = ตำแหน่งเริ่ม 0) | `tf` (true/false) | `output` (code ใช้ console.log) | `fill` (answer เป็นรายการคำตอบที่ยอมรับ), `timeLimitMin`, `maxAttempts`
- ระบบตัวอย่าง 10 ระบบอยู่ในไฟล์ `src/Showcase.html` (แก้หรือเพิ่ม `<textarea data-…>` ได้)
- ยังรองรับโจทย์ Python เดิม: ใส่ `lang: "python"` ในโจทย์ หรือบล็อก ```` ```python ```` ในใบความรู้

## ความปลอดภัยและข้อจำกัด
- เฉลยแบบทดสอบ และผลที่ควรได้ของชุดตรวจที่ซ่อน **ไม่ถูกส่งไปหน้าเว็บ** ตรวจที่เซิร์ฟเวอร์
- โค้ดของผู้เรียนรันใน iframe แบบ sandbox (แยก origin) จึงเข้าถึง token หรือข้อมูลของระบบไม่ได้
- ผลการตรวจหน้าเว็บส่งมาจากเครื่องนักศึกษา ผู้ที่ชำนาญอาจปลอมผลได้ ระบบจึงเก็บโค้ดทุกครั้งให้ครูสุ่มตรวจ ถ้าต้องการคะแนนที่เชื่อถือได้ 100% ให้ใช้ข้อ "ทายผลลัพธ์" ในแบบทดสอบ
- PIN เก็บแบบ SHA-256 + salt, ใส่ผิด 5 ครั้งล็อก 10 นาที, session หมดอายุ 6 ชั่วโมง
- ต้องต่ออินเทอร์เน็ตเพื่อโหลด Vue 3.4.38 และ Bootstrap 5.3.3 จาก cdnjs (ครั้งต่อไปเร็วขึ้นเพราะเบราว์เซอร์เก็บไว้)
- สำเนา Sheet ไปใช้ที่อื่น: รัน "1) ติดตั้งระบบ" ใหม่ ระบบตรวจพบสำเนาและรีเซ็ตรหัสลับเอง
- **อัปเกรดจากรุ่น Python**: วางไฟล์ใหม่ทั้งหมด แล้วเลือกเมนู "3) ใส่เนื้อหาและนักศึกษาตัวอย่าง" ระบบจะแทนเนื้อหาและเปลี่ยนชื่อวิชาให้ (ถ้ายังเป็นชื่อเดิม) คะแนนเก่าของรหัสกิจกรรมเดิมยังอยู่ ให้ล้างที่ ⚙️ ตั้งค่า ก่อนเปิดใช้
